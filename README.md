# CUSTOMER-ANALYSIS-FOR-RETAIL
This project focuses on analyzing retail store transaction data to uncover meaningful business insights related to customer behavior, product performance, and revenue trends.
### Project Overview
The objective of this project is to perform Exploratory Data Analysis (EDA) and generate insights from multiple datasets, including customers, products, and transactions. The analysis helps in understanding purchasing patterns, top-performing categories, and key revenue drivers.
### Dataset Description
The project uses three datasets:
Customer Data – Contains customer demographics (Customer_ID, gender, DOB, city)
Product Data – Includes product categories and sub-categories
Transaction Data – Contains transaction details like quantity, price, tax, and total amount
### Tools & Technologies Used
Python
Pandas – Data manipulation
NumPy – Numerical operations
Matplotlib & Seaborn – Data visualization
### Key Insights
Transaction Period: Identified the overall time range of transactions
Gender-Based Analysis: Product category preferences differ across genders
Top City: Identified the city contributing the highest number of customers
Store Performance: E-Shop generated the highest revenue and quantity sales
Category Revenue Insights: Strong contribution from Electronics and Clothing
Customer Behavior: Customers with more than 10 transactions were identified
Age Group Analysis (25–35):
Significant spending observed in Electronics and Books
Seasonal spending trends analyzed (Jan–Mar 2014)
### Conclusion
Customer purchasing behavior varies significantly across demographics, store types, and product categories. E-commerce channels and specific age groups contribute heavily to overall revenue, making them key focus areas for business growth.
